# v2.0 검증 기록

기존 차콜·민트 디자인을 유지한 기능 업데이트입니다. 실제 AWS 조회·조치·GeoIP 서비스는 연결하지 않았습니다.

## 신규 기능

`tests/v2-check.cjs`를 실제 Chrome에서 실행해 통과했습니다.

- 17개 지도 마커와 17개 리전 메뉴의 코드 유일성 및 모든 리전 선택/상세 연결.
- 서울 기본 상태: 위치를 가진 공격 1개 연결선, 위치 미상 1건 표시.
- 특정 공격 흐름 선택, IP 검색, 일반 Config 필터 적용 시 공격 연결선 제외.
- 연결선 끝점과 리전 마커 좌표 일치.
- 공격 흐름 키보드 선택 → 이벤트 상세 → 모의 IP·위치 정보 표시.
- 위치 미상과 사설 IP에 연결선 미표시, 상세 화면에 이유 표시.
- 휠 확대·축소 1~4배 제한 및 지도 위 휠 사용 중 페이지 스크롤 방지.
- 드래그 이동, 드래그를 클릭으로 오인하지 않는 동작.
- 방향키 이동, 지도 초기화, 전체/글로벌 선택 시 연결선 처리.
- 1440×900, 1920×1080, 390×844 레이아웃. 모바일 페이지 전체 가로 넘침 없음.
- 모션 감소 설정에 따라 공격 흐름 애니메이션 비활성화.
- JavaScript 예외 없음.

## 기존 기능 회귀 검증

`tests/browser-check.cjs`를 다시 실행해 메뉴, 지역 상세, 시간·소스·위험도·검색 필터, 승인 취소, 조치 후 재검증 대기, 성공·실패 분리, CSV 행 수, 지도 로딩 오류 후 재시도, 키보드 포커스 동작이 통과했습니다.

## 표현과 범위

곡면 투영과 음영으로 약한 입체감을 표현했습니다. 국가·리전·공격 출발 좌표는 동일 투영을 사용합니다. 공격선은 출발지와 목적지 관계이며 네트워크 라우팅 경로가 아닙니다. IP·도시 위치는 시연용으로 직접 연결한 모의 값이며 실제 GeoIP 조회 결과가 아닙니다. 실제 AWS 환경과 실물 모바일 기기는 검증하지 않았습니다.
