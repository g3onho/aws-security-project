# 대시보드 현재 작업 상태

갱신일: 2026-09-23

## 현재 구조

- `backend/soar/`: Flask 백엔드
- `frontend/static/js/store.js`: 단일 API 클라이언트
- `frontend/static/js/ui/constants.js`: 리전 지리정보와 화면용 열거값 (v20.4: `data.js`에서 이동)
- `backend/instance/dashboard.sqlite3`: 계정·실제 데이터 저장소

## 이번 변경

실제 데이터만 사용하는 구조로 정리했습니다. 생성형 이벤트·가상 자원·공격 IP·고정 관측 시각·취약점 카탈로그·모의 조치 결과를 제공하던 경로를 제거했습니다. 이전 생성 데이터 DB, 보관본, 화면 캡처, 색상 샘플, 데이터 생성 도구와 해당 데이터에 의존하던 검증·문서를 삭제했습니다.

기존 로그인 계정과 암호 해시는 새 DB에 유지했습니다. 운영 이벤트·조치·작업 이력은 옮기지 않았고, 계정의 데이터 접근 범위는 빈 목록으로 초기화했습니다. 브라우저 세션 쿠키 이름이 변경되어 다시 로그인해야 합니다.

인증·권한·CSRF·API 계약·조회 및 상태 전이 구조는 유지했습니다. 화면 클라이언트를 프런트엔드 폴더로 통일해 서버와 테스트가 같은 모듈을 사용합니다.

## 현재 동작과 남은 작업

실데이터 공급자는 미연결입니다. 로그인과 화면은 열리지만 데이터 조회는 `503 DATA_SOURCE_NOT_CONFIGURED`를 반환합니다. 미연결 상태를 정상 0건으로 바꾸지 않습니다. 쓰기는 기본 비활성화이며, 공급자 없이 워커를 실행하거나 조치를 접수할 수 없습니다.

`DATA_PROVIDER=aws` 선택 경계와 `AwsProvider`를 추가했다. boto3/STS 자격 증명을 확인한 뒤 Security Hub, EC2, CloudWatch CPU, Inspector 결과를 표준 읽기 모델로 매핑한다. 조치·재검증 공급자는 계속 비활성화되어 있다. 기본값 `DATA_PROVIDER=none`은 변경하지 않았다.

현재 화면은 표준 읽기 API의 `{data, meta}` 계약을 사용한다. 이벤트·요약·지표·취약점·인프라 상태·이력은 표준 경로에서 조회하고, 목록은 서명 커서를 따라 가져온다. 시나리오 카탈로그와 상세 증적처럼 API에 없는 정보는 표시하지 않는다. 모든 표준 API는 같은 계정·리전·자원 범위 판정을 사용한다. 이전 화면용 `/api/legacy/*` 경로는 삭제했다.

페이지네이션과 운영 환경별 IAM 권한 검증은 배포 전 확인해야 합니다. 현재까지 AWS 자원에 대한 변경은 수행하지 않았습니다.
