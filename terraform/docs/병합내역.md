## 2. 옮기지 않은 것 — 이미 B가 더 나았습니다

비교표를 쓸 때 B를 잘못 읽은 항목이 둘 있었습니다. 실제로 확인한 결과는 아래와 같습니다.

| 항목 | 비교표에 적었던 것 | 실제 B |
|---|---|---|
| **SSH 22** | "토글 없음 (상시 개방)" | **규칙 자체가 없음.** Session Manager 전용이라 A의 `enable_ssh` 토글이 필요 없습니다 |
| **대시보드 5000** | (A의 개선 항목) | 소스가 `var.vpc_cidr` 로 이미 내부 전용입니다 |

여기에 더해 B에는 **SSM VPC 엔드포인트가 기본 on** 이라, A에서 걸림돌이던
"NAT를 끄면 프라이빗 인스턴스에 Session Manager로 못 붙는다" 문제가 없습니다.

A의 `enable_ssh` 토글은 **옮기지 않았습니다.** 없는 규칙을 끄는 토글이라 의미가 없습니다.
