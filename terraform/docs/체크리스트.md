## 잔여 위험 (발표에서 먼저 언급하면 좋습니다)

숨기면 감점이고, 먼저 밝히면 가점입니다.

1. **HTTPS 미적용** — ALB/NLB TLS 리스너와 ACM 인증서 미구성. HTTP 평문 전송.
2. **ALB가 0.0.0.0/0** — 뒷단이 DVWA입니다. 실습 중에는 `admin_cidr` 로 좁히는 것을 권장합니다.
3. **로컬 state** — `backend.tf.example` 상태. 팀 동시 작업 시 충돌 위험.
4. **DVWA는 의도적으로 취약** — 공격 시연 대상이므로 개선 대상이 아님. 단, `admin_cidr` 밖에서 접근 불가해야 함.
5. **NAT Gateway 기본 off** — VPC 엔드포인트로 SSM은 되지만, 패키지 설치엔 NAT가 필요합니다.
